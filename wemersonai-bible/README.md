# Wemerson AI — base de conhecimento de atendimento (BlockCapital)

Base estruturada com as respostas oficiais para atender clientes/alunos da BlockCapital
(CRM · Carteira IA · VantageNode · comercial). Substitui o antigo app offline.

## Estrutura
- `ARQUIVO-MAE.md` — a bíblia: o que é, regras de ouro, voz, fluxo, índice.
- `knowledge/` — as respostas por área:
  - `crm.md` — Carteira Rumo ao Milhão (o carro-chefe)
  - `carteira-ia.md` — Carteira IA
  - `vantagenode-produto.md` — produto VantageNode
  - `blockcapital-comercial.md` — planos, pagamento, reembolso, acesso
  - `voz-atendimento.md` — como escrever a resposta

## Como usar
Cole a dúvida do cliente e responda a partir da base, na linguagem acessível.
NUNCA inventar: se não estiver na base, confirmar / encaminhar pro suporte
(suporte@theblockcapital.net).

## Como crescer a base
Dúvida nova + resposta oficial → adicionar no arquivo de `knowledge/` da área certa,
no mesmo formato (assunto · resposta).

## Segurança
NÃO versionar senhas/credenciais aqui. Segredos ficam fora do repositório (.gitignore).
